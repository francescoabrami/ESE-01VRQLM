We began by calculating the bandwidth of the amplifier F = GBP / (1 + |AV|) = 180KHz
We set the waveform generator to output a 1kHz square wave with 2Vpp and 50% Duty cycle.
With this input the required SR would be 2PI * F * dV = 10.2V/us way more than the typical SR of the uA741, which is 0.5V/us. This makes the output rise time limited by the SR, Giving a theoretical rise time of 14.5us.
This result matches the waveform of Vout, which is a straight ramp of m = 0.5V/us.

Now we set the $V_{pp}$ of the input signal to be much smaller: 0.1 $V_{pp}$
With this new signal the required SR is roughly the same as the typical value of SR of the OpAmp, so the amplifier is "strong enough" to follow the input signal. This is clearly visible in the waveform of $V_{out}$: the curve now is totally different than before; it is an exponential rise with a rise time an order of magnitude faster than the previous experiment. This exponential rise is the bandwidth effect.\\

\subsubsection*{Virtual ground}

We now look at both input terminals of the OpAmp: $V+$ and $V-$.
In an ideal OpAmp these two terminals should be both at the same voltage, in this case $V+$ is connected to ground: we should read 0V on both of them.
When we measure $V+$ we see a very noisy signal of just 17.6 mV and an average value of 540 uV. This very small signal is just noise and is really close to being 0.
On the $V-$ terminal we see a very small and very noisy sinusoidal signal. This is due to the fact that in a real differential amplifier $V-$ = $\frac{-V_{out}}{A}$ . In this case $A$ is $2 * 10^5$: so we theoretically expect a signal 200'000 times smaller that $V_{out}$ and 180 degrees out of phase.

\subsubsection*{Output dynamic range}  % TODO GRAPH

From the datasheet we know that the OpAmp can only output a current of 25 mA. The input signal will always be a 1 kHz sinusoidal with 1 $V_{pp}$, giving us an output of a 1KHz sinusoidal 4.55 $V_{pp}$.

%  SIN NON TAGLAUTA

For the first measurement we hook up the output to a 1 kOhm load, using I = V / R with V = 2.27 V and R = 1 kOhm we get an expected current of 2.27 mA, well within the max of the OpAmp, this will have a negligible effect on the waveform of $V_{out}$ because the OpAmp has enough "strength" to provide that current: we see a waveform that is identical to the one without any load.
We now hook up a heavier load of 100 Ohm. This requires a current of 22.7 mA, which is around the typical current of the OpAmp (and higher than the minimum possible value). This caused the $V_{out}$ waveform to be flattened at about +2V, which means that the transistors inside the OpAmp gave up following the input signal when the output current exceeded 20mA.
We don't know why the waveform is only cut in the positive values and not in the negatives.
